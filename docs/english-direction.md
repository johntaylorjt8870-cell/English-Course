# قاعدة الاتجاه: العربية RTL والإنجليزية LTR دائمًا

> الواجهة عربية (`dir="rtl"`)، لكن **كل وحدة إنجليزية يجب أن تُعرض داخل عازل LTR**.
> مخالفة هذه القاعدة تعكس ترتيب الكلمات (مثلًا `orange an` بدل `an orange`).

## القواعد الخمس

1. **الجملة/العبارة الإنجليزية الكاملة** ← داخل `<En>` أو `dir="ltr"` (مثال: `She is a teacher.`).
2. **النص المختلط** (عربي + إنجليزي في سطر واحد) ← عبر `LatinRuns` من `src/shared/bidi.tsx`
   — يعزل كل **مقطع** لاتيني متصل كوحدة واحدة. يشمل ذلك عناوين الدرس 1 مثل
   `Subject · Verb · Object` و `ما هو الـ Subject؟`.
3. **ممنوع منعًا باتًا** تقسيم الإنجليزية إلى كلمات معزولة (`split(/(\s+)/)` + تغليف كل كلمة) —
   هذا يعكس الترتيب حتمًا داخل RTL. الفحص الآلي يرفضه.
4. **التراكيب** (مثل `Subject + Verb + Object`) و**الأداة + الاسم** (`an apple`) و**باني الجمل**
   و**الاختبارات** و**الجداول** ← صفوف `dir="ltr"` دائمًا.
5. **الأسهم التوضيحية** (`←`) والشروح (`EN = AR`) تبقى بسياقها العربي — لا تعزلها عن سياقها.

## أمثلة صحيحة من الكود

```tsx
import { LatinRuns } from "../../shared/bidi";

// وحدة إنجليزية داخل سطر عربي:
<span dir="ltr"><En>Do / Does</En> ← <En>Present Simple</En></span>

// نص مختلط: يعزل "Verb to be" كوحدة واحدة بترتيبها الصحيح:
<LatinRuns text="نستخدم Verb to be مع الصفات" />

// صف تركيب: المقال + الاسم بترتيب LTR:
<div dir="ltr"><En>an</En> <En>orange</En></div>
```

## حالات مقصودة ليست أخطاء

- `a apple` / `a egg` في أمثلة «صحح الخطأ» — أخطاء متعمدة للتدريب.
- `the` مع الجمع في سياق a/then/the — حسب الدرس.
- شروح عربية فيها كلمات إنجليزية مفردة (`s`، `does`) — آمنة لأنها كلمة واحدة.

## الأزواج «English = Arabic» والفحص الآلي للمحرك (BIDI)

- **المشكلة:** في فقرة RTL تُعرض العبارة `already = بالفعل` بصريًا هكذا: `بالفعل already =`.
  الحل بنيوي في `src/shared/bidi.tsx`: أي مقطع إنجليزي يتبعه فاصل صريح (`= : – — → ( . ! ?` …)
  ثم عربي يُجمع مع العربي في غلاف `dir="ltr"` واحد (`ltr-pair`). لا تُدرج محارف تحكم يونيكود في البيانات.
- **`<EnAr en ar sep>`**: الوحدة نفسها للزوج الإنجليزي + الشرح العربي داخل صف مرن (flex) — تُستخدم بدل
  `<En>…</En>` متبوعًا بعربي في الصفوف المرنة.
- **الرموز** (`✅ ❌ ⏪ ㊴ «»`) تُعدّ جزءًا من المقطع الإنجليزي حتى لا ينكسر الزوج.
- **البدائل «English A أم English B؟»:** إذا فصلت أداة عربية (`أم` / `أو`) بين عبارتين إنجليزيتين
  (مثل `IQ200 — had danced أم was dancing؟`) تُجمَع البدائل والأداة بينها في غلاف `ltr-pair` واحد:
  العبارتان بترتيبهما المكتوب، والأداة العربية بينهما، و`؟` العربية داخل الغلاف.
- **الأقواس:** القوس المفتوح `(` يجمع الإنجليزية بأول عبارة عربية **فقط** إذا أُغلِق القوس مباشرةً
  بعدها — `Past Perfect (الماضي المثالي)` شرحٌ للعبارة الإنجليزية. أما إذا فتح القوس جملة عربية كاملة
  (`when / while (الدرسان 25 و26)`) فالجملة كلها تبقى في سياق RTL ويُعزل المقطع الإنجليزي وحده،
  وإلا التصق القوس بطرف العازل وابتعد عن محتواه. وكذلك أي قوس غير متوازن داخل مقطع لاتيني
  (`حدث ماضٍ واحد: Yesterday, I visited… (بلا had).`) يبقى خارج العازل LTR مع ما بعده، فيعكسه
  المتصفح في مكانه الصحيح (`splitUnbalancedParens` في `src/shared/bidi.tsx`). الأقواس المتوازنة
  داخل المقطع الإنجليزي (`(already) = بالفعل`) لا تُمَس.
- **الفحص:** `scripts/audit-bidi-mixed.mjs` يفتح الواجهة الحقيقية في jsdom، يمرّ على كل خطوات كل درس،
  ويفحص كل فقرة معروضة بخوارزمية UBA (`bidi-js`) عبر `scripts/lib/bidi-sim.mjs`.
  - الدروس **6 و27–31**: صفر مخالفات (مع قائمة استثناء قصيرة موثّقة داخل الملف للإيجابيات الكاذبة).
  - الدروس **1–26**: حد أعلى لكل درس في `scripts/bidi-baseline.json` (لا زيادة). لتحديث الحد بعد إصلاح متعمد:
    `node scripts/audit-bidi-mixed.mjs --write-baseline`.
- **الاختبارات:** `scripts/test-bidi-rendering.mjs` يُصيّر `LatinRuns`/`EnAr` الحقيقيين ويتحقق من الترتيب البصري
  لحالات `already = بالفعل`، و`S + have/has + V3`، و`S + had + V3`، و`for/since`، والأقواس، والشرطات المائلة،
  والجمل الإنجليزية مع شرح عربي، مع حالات ضابطة سلبية تثبت أن الفحص يلتقط الخطأ الخام.
- **علامات التبويبات:** الزاحف يمرّ على خطوات الدرس فقط، لذلك يفحص `scripts/audit-lesson27.mjs`
  علامات «الاختبار» و«الحلول» و«المعلم» (مقفلة ومفتوحة) صراحةً بمسح BIDI كامل لكل علامة.
- **حدود معروفة:** الزاحف ينقر «التالي» فقط ولا يجيب الاختبارات، فتغذية الإجابات لا تُفحص بهذا الفحص
  (تُغطّيها فحوص الدروس). لم يُجرَ فحص بصري في متصفح حي.
