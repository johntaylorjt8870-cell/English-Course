# قاعدة الاتجاه: العربية RTL والإنجليزية LTR دائمًا

> الواجهة عربية (`dir="rtl"`)، لكن **كل وحدة إنجليزية يجب أن تُعرض داخل عازل LTR**.
> مخالفة هذه القاعدة تعكس ترتيب الكلمات (مثلًا `orange an` بدل `an orange`).

## القواعد الخمس

1. **الجملة/العبارة الإنجليزية الكاملة** ← داخل `<En>` أو `dir="ltr"` (مثال: `She is a teacher.`).
2. **النص المختلط** (عربي + إنجليزي في سطر واحد) ← عبر `LatinRuns` من `src/shared/bidi.tsx`
   — يعزل كل **مقطع** لاتيني متصل كوحدة واحدة.
3. **ممنوع منعًا باتًا** تقسيم الإنجليزية إلى كلمات معزولة (`split(/(\s+)/)` + تغليف كل كلمة) —
   هذا يعكس الترتيب حتمًا داخل RTL. الفحص الآلي يرفضه.
4. **التراكيب** (مثل `Subject + Verb + Object`) و**الأداة + الاسم** (`an apple`) و**باني الجمل**
   و**الاختبارات** و**الجداول** ← صفوف `dir="ltr"` دائمًا.
5. **الأسهم التوضيحية** (`←`) والشروح (`EN = AR`) تبقى بسياقها العربي — لا تعزلها عن سياقها.

## أمثلة صحيحة من الكود

```tsx
import { LatinRuns } from "../../shared/bidi";

// وحدة إنجليزية داخل سطر عربي:
<span dir="ltr"><En>Do / Does</En> ← <En>Present Simple</En></span>

// نص مختلط: يعزل "Verb to be" كوحدة واحدة بترتيبها الصحيح:
<LatinRuns text="نستخدم Verb to be مع الصفات" />

// صف تركيب: المقال + الاسم بترتيب LTR:
<div dir="ltr"><En>an</En> <En>orange</En></div>
```

## الفحص قبل الدمج

```bash
npm run check:english-direction   # يفحص غياب محرك الانعكاس + الأنماط المعكوسة + التجميعات
npm run build                      # يجب أن ينجح البناء
```

## حالات مقصودة ليست أخطاء

- `a apple` / `a egg` في أمثلة «صحح الخطأ» — أخطاء متعمدة للتدريب.
- `the` مع الجمع في سياق a/then/the — حسب الدرس.
- شروح عربية فيها كلمات إنجليزية مفردة (`s`، `does`) — آمنة لأنها كلمة واحدة.
