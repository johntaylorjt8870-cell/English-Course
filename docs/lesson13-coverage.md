# الدرس 13 — تغطية المصدر (Source Coverage Ledger)

> **القاعدة:** نص المصدر هو المرجع الوحيد. كل شرح، مثال، مقارنة، تمرين، سؤال، إجابة، تحدي، وترتيب
> يجب أن يظهر في الدرس كما هو — بلا تلخيص ولا حذف ولا إعادة صياغة ولا إعادة ترتيب.
> هذا الملف يثبت المطابقة سطرًا بسطر: كل قسم من المصدر ⇄ الشريحة التي تعرضه.

## 3) تحقق أمانة النص (Fidelity)

فحص آلي مباشر على `data.ts` (سكربت تحقق مؤقت أثناء التنفيذ، 420 عبارة + 34 جملة شرائح):

- **420/420** عبارة عربية/إنجليزية من المصدر موجودة نصًا حرفيًا.
- **34/34** جملة عُرضت كشرائح أدوار (PartsLine) — أُعيد بناؤها من أجزائها بنفس الترتيب الإنجليزي بالضبط
  (مثال: `I` + `visited` + `the aquarium` + `yesterday`).
- الصيغ الأربع بترتيبها الصحيح: `Subject + Past Verb` · `Subject + didn't + Base Verb` ·
  `Did + Subject + Base Verb?` · `Wh-word + did + Subject + Base Verb?` — وأيضًا الصيغ الحرفية كما في §4:
  `Subject + did not + base verb` و`Subject + didn't + base verb`.
- ترتيب الأقسام محفوظ: الشرائح 3→22 تحمل `step` من 1 إلى 20 بالترتيب.

## 4) إضافات توضيحية (معلَّمة صراحةً داخل الدرس — ليست من نص المصدر)

1. **§22 و §23** — المصدر يعطي الجمل والتعليمة فقط، والإجابات مُشتقة بتطبيق قاعدة الدرس نفسها
   (`didn't + Base Verb` / `Did + Subject + Base Verb?`) وتظهر بزر «أظهر النفي/أظهر السؤال».
2. **§27 و §30** — المصدر يعطي المهام بلا نموذج، والأسئلة المفتوحة تعرض نموذجًا مقترحًا موسومًا:
   «نموذج مقترح مبني على قاعدة الدرس نفسها — إضافة توضيحية وليست من نص المصدر.»
3. **§29** — لا قائمة إجابات في المصدر، والإجابات مستخرجة من الفقرة نفسها، ويظهر بجانبها
   «إجابات مستخرجة من النص نفسه — ليست قائمة إجابات مقدَّمة في المصدر.» مع ذكر السطر المرجعي.
4. **§16 `Who`** — بقي كما ورد في المصدر (معنى فقط، بلا أمثلة مضافَة).
5. الغلاف وخطة الدرس وأزرار «أظهر» ولوحات المقارنة: أغلفة تفاعلية حول المحتوى، لا تحلّ محله.

## 5) الاتجاه (RTL/LTR)

- العربية RTL كما هي، وكل وحدة إنجليزية داخل عازل LTR (`<En>` / `dir="ltr"` / `.ltr-row`).
- النص المختلط عبر `LatinRuns` (عزل على مستوى المقطع، وليس الكلمة).
- التحقق الآلي: `npm run check:english-direction` (233 تأكيدًا، منها فحص صيغ الدرس 13)
  و`npm run audit:english-direction` (66 تأكيدًا، منها ترتيب الصيغ الأربع في HTML المُعرَض فعليًا + عرض كل الشرائح 37/37 بلا أخطاء).
